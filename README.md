# Grace's Drum Machine

## Live Demo

[Open the Drum Machine](https://graceelliott8374-tech.github.io/react-drum-machine/)

An interactive drum machine built with React. Originally created during bootcamp, it has since been refactored and migrated from Create React App to Vite.

## Features

- Nine playable drum sounds
- Mouse and keyboard controls
- Displays the name of the selected sound
- Responsive layout
- Animated glowing interface
- Fast Vite development and production builds

## Keyboard Controls

| Key | Sound        |
| --- | ------------ |
| Q   | Cymbal       |
| W   | Kick and Hat |
| E   | Crash        |
| A   | Bass         |
| S   | Scratch      |
| D   | Side Stick   |
| Z   | Snare        |
| X   | Punchy Kick  |
| C   | Drop         |

## Run Locally

1. Clone the repository.
2. Open the project directory.
3. Install the dependencies:

   npm install

4. Start the development server:

   npm run dev

## Available Scripts

- `npm run dev` — starts the development server
- `npm run build` — creates a production build
- `npm run preview` — previews the production build
- `npm run deploy` — publishes the site to GitHub Pages
